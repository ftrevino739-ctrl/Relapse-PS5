# JailbreakX — PS5 7.00 - 13.60

Supported firmware: 7.00 through 13.60.

## Setup Tutorial

1. On your PS5 go to **Settings → Network → Set Up Internet Connection**.
2. Select your network → **Options** → **Advanced Settings**.
3. Set **DNS Settings** to **Manual**.
4. Primary DNS: **45.56.67.85**
5. Secondary DNS: leave empty or use `1.1.1.1`.
6. Save and connect.
7. Open **User's Guide**.
8. If it does not redirect automatically, enter this URL:  
   `https://ftrevino739-ctrl.github.io/Relapse-PS5/`

After a successful run the ELF loader listens on port **9021**.

## Stability notes
WebKit may need several attempts. Reload the page if the browser stalls. The kernel exploit may hang or panic the console — reboot before trying again.
